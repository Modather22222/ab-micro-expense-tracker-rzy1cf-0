# Micro-Expense Tracker

A sleek offline Flutter expense tracker: a fl_chart spending dashboard (pie chart by category plus a 7-day bar chart), a quick-add bottom sheet with category chips, and a filterable, swipe-to-delete expense history. Ships with in-memory seed data — no network or platform channels.

## Run

```sh
flutter pub get
flutter run
```

Requires Flutter stable 3.47. Use the History tab's category chips to filter and the Quick add button to log new expenses.
